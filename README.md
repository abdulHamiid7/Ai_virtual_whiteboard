🖐️ AI Virtual Whiteboard

An AI-powered virtual whiteboard built with Python and Computer Vision that allows users to draw and interact with a digital canvas using hand gestures.

Instead of using a physical mouse or touchscreen, the system uses a webcam to detect the user's hand and track finger movements in real time.

✨ Features
🖐️ Real-time hand detection
☝️ Finger tracking
✏️ Draw using your finger
🎨 Virtual drawing canvas
🧹 Erase drawings using gestures
🖥️ Real-time webcam processing
⚡ Smooth and responsive interaction
🛠️ Technologies Used
Python
OpenCV – Image processing and webcam handling
MediaPipe – Hand tracking and landmark detection
NumPy – Image and array processing
